2 ЗАВДАННЯ
     Метою завдання є створення консольного PHP-застосунку «Продовольчий магазин "Весна"». Програма має забезпечувати взаємодію з користувачем через термінал та надавати набір функцій для моделювання процесу купівлі продуктів. Зокрема, користувач може переглядати список доступних товарів, додавати їх до кошика з вказанням кількості, отримувати підсумковий рахунок з детальним чеком, а також налаштовувати свій профіль, вводячи ім’я та вік. Інтерфейс має бути зрозумілим, а всі введення — перевірятися на коректність, включаючи наявність пункту меню, товару, правильність кількості, формату імені та віку. Програма повинна мати зрозумілу структуру, підтримувати обробку помилок, надавати зрозумілий текстовий інтерфейс і відповідати заданому функціоналу.

     Функція форматованого виведення таблиці — printTable відповідає за виведення табличних даних у консоль у вигляді акуратно вирівняної таблиці. Вона приймає два параметри: заголовки стовпців ($headers) і рядки таблиці ($rows). Спочатку функція визначає ширину кожного стовпця, щоб усі значення відображалися вирівняно. Потім за допомогою допоміжної функції mb_str_pad (що також реалізована нижче) кожне значення доповнюється пробілами до потрібної довжини. Це особливо важливо при роботі з кирилицею, бо стандартні функції роботи з рядками у PHP можуть неправильно рахувати символи.
45 function printTable($headers, $rows) {
46     $widths = array_map(fn($h) => mb_strlen($h, 'UTF-8'), $headers);
47 
48     foreach ($rows as $row) {
49         foreach ($row as $i => $val) {
50             $widths[$i] = max($widths[$i], mb_strlen((string)$val, 'UTF-8'));
51         }
52     }
53 
54     foreach ($headers as $i => $head) {
55         echo mb_str_pad($head, $widths[$i]) . '  ';
56     }
57     echo "\n";
58 
59     foreach ($rows as $row) {
60         foreach ($row as $i => $val) {
61             echo mb_str_pad((string)$val, $widths[$i]) . '  ';
62         }
63         echo "\n";
64     }
65 }

     Реалізовано допоміжну функцію для доповнення рядків — mb_str_pad. Ця функція — розширена версія стандартної str_pad, яка працює коректно з багатобайтовими символами (наприклад, українськими літерами). Вона використовується у функції printTable для вирівнювання стовпців. Вона визначає, скільки пробілів потрібно додати до кінця рядка, щоб вирівняти його довжину до бажаної, і повертає новий рядок із заповненням.
66 function mb_str_pad($str, $len, $pad_char = ' ', $encoding = 'UTF-8') {
67     $padLen = $len - mb_strlen($str, $encoding);
68     return $padLen > 0 ? $str . str_repeat($pad_char, $padLen) : $str;
69 }

     Далі було реалізовано функцію для формування рахунку — showBill. Ця функція відповідає за підсумковий розрахунок вартості товарів, які знаходяться у кошику користувача. Спочатку перевіряється, чи кошик порожній — якщо так, виводиться відповідне повідомлення та сума до сплати 0. У протилежному випадку створюється таблиця, де для кожного товару виводиться його порядковий номер, назва, ціна за одиницю, кількість та загальна вартість (ціна × кількість). Після цього розраховується підсумкова сума за всі товари, і вона виводиться окремо. Цей блок дозволяє користувачу побачити остаточний чек перед завершенням покупок або оплатою. Це логічне завершення основної торгової взаємодії в програмі.
125 function showBill($products, $cart) {
126     if (empty($cart)) {
127         echo "КОШИК ПОРОЖНІЙ\n";
128         echo "РАЗОМ ДО СПЛАТИ: 0\n";
129         return;
130     }
131 
132     $headers = ['№', 'НАЗВА', 'ЦІНА', 'КІЛЬКІСТЬ', 'ВАРТІСТЬ'];
133     $rows = [];
134     $i = 1;
135     $total = 0;
136     foreach ($cart as $id => $qty) {
137         $name = $products[$id]['name'];
138         $price = $products[$id]['price'];
139         $cost = $price * $qty;
140         $rows[] = [$i++, $name, $price, $qty, $cost];
141         $total += $cost;
142     }
143 
144     printTable($headers, $rows);
145 
146     echo "РАЗОМ ДО СПЛАТИ: $total\n";
147     echo "\n";
148 }

     Потім було реалізовано функцію для налаштування профілю користувача— setupProfile. Ця функція надає змогу користувачу ввести свої особисті дані: ім’я та вік. На першому етапі програма просить ввести ім’я, і за допомогою регулярного виразу перевіряє, чи воно складається лише з літер, апострофів, дефісів та пробілів. Якщо ім’я не відповідає формату — виводиться повідомлення про помилку, і користувачеві пропонується ввести його ще раз.
     Далі перевіряється вік: він має бути числом у діапазоні від 7 до 150 років. Якщо користувач вказує недопустиме значення, його також просять повторити введення. Після успішного введення обох полів, програма записує дані в профіль та виводить підтвердження.
149 function setupProfile(&$profile) {
150     while (true) {

157         }
158         
159         break;
160     }
161 
162     while (true) {
163         echo "Ваш вік: ";

165         if (!is_numeric($age) || $age < 7 || $age > 150) {

167             continue;
168         }
169         break;
170     }
171 
172     echo "\n";
173     $profile['name'] = $name;
174     $profile['age'] = (int)$age;
175     echo "Ваше ім'я: {$profile['name']}\nВаш вік: {$profile['age']}\n";
176     echo "\n";
