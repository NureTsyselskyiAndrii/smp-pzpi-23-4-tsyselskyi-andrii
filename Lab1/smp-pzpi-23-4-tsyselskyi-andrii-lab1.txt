     Функція select_group_interactively використовується тоді, коли групу не було вказано в аргументах командного рядка. Вона виводить список доступних груп і дає користувачу можливість вибрати одну. Якщо груп немає — повідомляється про це. Якщо користувач обирає "ВИХІД", скрипт завершує виконання. Обрана група записується у змінну chosen_group.

     Функція format_time переводить час у формат, який приймає Google Calendar (наприклад, 14:00 → 2:00 PM).
43 format_time() {
44     split(time, formatted_time, ":")
45     hour = int(formatted_time[1])
46     min = formatted_time[2]
47     suffix = "AM"
48     if (hour == 0) {
49         hour = 12
50     } else if (hour >= 12) {
51         if (hour > 12) hour -= 12
52         suffix = "PM"
53     }
54     return hour ":" min " " suffix
55 }
